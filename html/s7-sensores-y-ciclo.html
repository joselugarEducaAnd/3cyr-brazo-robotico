Misión ingeniería: construye tu brazo robótico

S7 · Sensores y ciclo

Que el robot decida solo

Hasta ahora el brazo hacía lo que vosotros le mandabais con los pulsadores. Hoy dais el paso que convierte una máquina teledirigida en un robot de verdad: que mire la pieza y decida él a qué bandeja llevarla.

El sensor de luz (LDR)

El shield lleva un LDR en el pin A1. Es una resistencia que cambia según la luz que recibe, así que sirve para saber si lo que tiene delante es claro u oscuro:

  • Pieza clara → refleja mucha luz → el valor sube.
  • Pieza oscura → refleja poca luz → el valor baja.

Se lee con Leer analógica Pin A1 y da un número de 0 a 1023.

Práctica guiada · Calibrar el umbral

El valor que separa «claro» de «oscuro» no se puede saber de antemano: depende de la luz que haya en el sitio donde esté vuestro brazo. Hay que medirlo. Esto se llama calibrar y es lo que se hace con cualquier sensor real.

  1. Programa: en Bucle, escribir en el puerto serie Leer analógica Pin A1, y debajo Esperar 300 milisegundos. (El bloque del puerto serie está en Comunicaciones › Puerto serie.)
  2. Subid el programa y abrid el monitor serie.
  3. Poned una pieza clara bajo el sensor. Apuntad el valor: ______
  4. Poned una pieza oscura. Apuntad el valor: ______
  5. Vuestro umbral es el punto medio entre los dos. Por ejemplo, si sale 700 y 300, el umbral es 500.

Si los dos valores salen casi iguales, el sensor no distingue las piezas: acercadlo más, o usad piezas con más contraste (blanca y negra, no dos grises).

El ciclo completo

Un ciclo es la secuencia que el robot repite con cada pieza. El vuestro es este:

Fijaos en la forma del programa: hay un condicional dentro de otro. Primero compruebas si han pulsado el botón; solo si lo han pulsado, compruebas si la pieza es clara u oscura. Eso se llama condicionales anidadas y es la estructura que usan casi todos los automatismos.

Tarea · El clasificador

Cread un proyecto UNO llamado S7 clasificador y programad el ciclo entero.

La estructura, en palabras:

  1. Si Leer digital Pin 2 es ON (han puesto una pieza y pulsan):
    1. Leer Leer analógica Pin A1 y guardarlo en una variable luz.
    2. Si luz < vuestro umbral → base (pin 7) a 45°.
    3. Si no → base (pin 7) a 135°.
    4. Bajar el antebrazo (pin 8), esperar, subirlo.
    5. Volver la base a 90°.

Mínimo para dar la tarea por hecha: el brazo distingue las dos piezas y lleva cada una a un lado distinto, aunque haga falta colocársela a mano.

Si queréis ir más allá, elegid una o varias:

  • Encender el LED azul (pin 13) con las piezas claras y el rojo (pin 12) con las oscuras.
  • Un pitido con el zumbador (pin 5) al terminar cada pieza.
  • Una tercera bandeja para las piezas intermedias, con un tercer caso.
  • Un contador de piezas clasificadas que se muestre en el monitor serie.
